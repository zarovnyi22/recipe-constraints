# Recipe Constraints

Технолог пише словами, який продукт хоче; сервіс повертає рецептуру в грамах на 1 кг або чесно
пояснює, чому такої немає і що послабити. Модель лише структурує запит, рахує LP-розв'язувач,
відповідність перевіряє окремий незалежний код.

> Заготовка (крок B1a). Розділи заповнюються в наступних кроках; фінальна звірка з кодом — B6.

## Запуск

```bash
cp .env.example .env      # вписати GEMINI_API_KEY (і за потреби GROQ_API_KEY)
make up                   # db + api на 127.0.0.1
make health
make test                 # ruff + pytest, offline, БД recipe_test
```

Порти: api 8020, db 127.0.0.1:5434. Swagger UI: http://localhost:8020/docs.

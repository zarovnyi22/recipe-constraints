# Нотатки між кроками

## Дані (B1b)
- Конвенція: `carbs` = засвоювані БЕЗ клітковини і поліолів (ЄС); `polyols` — «інші» вуглеводи з
  енергією ≠ 4 (еритрит, мальтитол, лимонна/оцтова кислота). Atwater: low = 4P+9F+4C, high = low +
  2·fibre + 2.4·polyols, допуск ±15 % (+2 ккал). `app.data.energy_bounds` — спільна функція;
  verify.py (B3a) має писати свою незалежну версію.
- `sweetness` — сахарозний еквівалент на 1 г інгредієнта; `sweetness_min` шаблону — г-екв на 100 г
  ГОТОВОГО продукту = Σ(x·sweet)/10.
- Ролі шаблону: `one_of` (yogurt: base і culture) — розв'язувач перебирає варіанти (7×3 LP), `blend` —
  звичайна суміш. Інгредієнт має `min_dose_pct`, якщо він використаний (закваски: DVS 0,01–0,05 %,
  виробнича 1–3 %); `dose_limits_pct` шаблону суворіші за інгредієнт (еритрит ≤ 8 % у м'яких).
- `flavor_min_pct` ролі fruit (йогурти): якщо просять смак — мінімум ролі; без смаку fruit може бути 0.
- Печиво: `moisture_loss_pct` 10 → маса сирої рецептури = 1000/(1−0,10) = 1111,1 г, відсотки ролей — від
  неї; нутрієнти на 100 г готового = Σ(x·n)/1000; ціна/кг готового = Σ(x·price)/1000 (партія = рівно 1 кг).
- Ціни — оцінки; опори з посиланнями в `PRICES.md` лише для цукру, молока-сировини, олії (борошно — частково, полуниця IQF — не знайдено). Після правок базова рецептура йогурта коштує 44,0 грн/кг (було 47,3).
- `glucose_syrup`: DE 40, цукри 40 г/100 г (Atwater сходиться). Мед, WPC80, ізоляти — верхня межа цін. Еталони — типові значення, не вимірена вибірка.
- `date_paste` має `added_sugar: true` (підсолоджувач/зв'язка), сухофрукти-ціле (родзинки) — ні.
- Алергени: `plant_margarine` = soybeans (лецитин, консервативно); `spice_blend` may_contain celery, mustard.

## Розгортання (B2a)
- `expand(spec, data) → Expansion`: `variables` (усі інгредієнти ролей шаблону), `constraints`
  (LinearConstraint, op `<=`/`>=`, `==` лише для маси), `one_of` {роль: кандидати} — розв'язувач
  перебирає, `min_dose_g` — напівнеперервні мінімуми (якщо використано) для B2b.
- Масштаб коефіцієнтів: ліва частина в одиницях `unit` (г/100 г = Σx·n/1000; грн/кг = Σx·ціна/1000;
  % рецептури = 100·x/batch_mass_g), тож `rhs` — людське число для «послабити з 45 до 52».
- `group` — одна вимога → кілька рядків (reduced_sugars: цукри + енергія; `==` → смуга ±2 %;
  satfat_low: грами з запасом 0,1 г + ≤10 % енергії). Послаблювати/показувати — по `group`.
- Виключення (алергени, дієти, інгредієнти, no_added_sugar, без підсолоджувачів) — рядок
  Σx ≤ 0, змінні НЕ видаляються. Алергени й дієти: `auto_relax: false` (лише «інший варіант»).
- Характерний інгредієнт (flavor) — жорстко: ≥ flavor_min_pct ролі і ≥ кожного іншого інгредієнта
  ролі. Без flavor_min_pct і з min_pct ролі 0 → unsupported. must_include без % → max(5 %,
  мінімум ролі / flavor_min_pct), обрізано дозволеним шаблоном (role max, Σ max доз) — запис в
  assumptions, статус не partial; unsupported лише якщо інгредієнта немає в базі або в шаблоні.
- Підсолоджувач = group sweeteners, не added_sugar, sweetness ≥ 0,1 — за Регл. 1333/2008
  (додаток I, «підсолоджувачі»): еритрит E968, стевіол-глікозиди E960, мальтит E965 — так;
  полідекстроза E1200 — ні (наповнювач); мед, фінікова паста — додані цукри, не підсолоджувачі.
- fibre_* — АБО: ≥ 3/6 г на 100 г, АБО ≥ 1,5/3 г на 100 ккал (рядки з `alt`, `either_or`
  {group: [per_100g, per_100kcal]}; розв'язувач перебирає альтернативи, як one_of).
- Напої: пороги для рідин (на 100 мл) застосовано до 100 г (густина ≈ 1) — в assumptions.
- Нічого не губиться: виключення, якого в шаблоні немає, і інгредієнт, якого немає в базі, —
  рядок в `assumptions` (виконано автоматично).

## Розв'язувач (B2b)
- `solve(exp, data) → Recipe | Infeasible`; `best_recipe` — найдешевша округлена рецептура по всіх
  варіантах (one_of × either_or; йогурт 21 LP), `explain` — конфлікт, послаблення, альтернативи.
- Округлення: 0,1 г, **нижче 1 г — 0,01 г** (стевія 0,04 г давала 0,9 г сах. екв./100 г; при 0,1 г
  вона зникала і ламала sweetness_min — відхилення від «0,1 г» SPEC свідоме). Цілі соті грама,
  різниця — у найбільший інгредієнт ролі base (без base — найбільший загалом), Σ = маса рівно
  (1000,00; печиво 1111,10). Перевірка всіх рядків варіанта; не тримається → LP з запасом ε 0,5 %,
  потім 2 % (`margin_pct` у Recipe). Juice/cookie/ketchup базові вже йдуть через ε 0,5 %.
- `LinearConstraint.relax`: `value` (нове число, «до 3 значущих» назовні) або `drop` (твердження,
  виключення — цілком). Еластичний LP: вага 1/|rhs| (1 для rhs 0), drop ×10.
- Порядок explain: шаблон без м'яких нездійсненний → `template_infeasible` (500); конфлікт —
  deletion filter по групах; спільне послаблення — спершу лише групи конфлікту, потім усі;
  альтернативи — кожна група окремо; `auto_relax: false` (алергени, дієти) → лише `other_options`
  з попередженням. Кожна зміна — через `_verify` (повний розв'язок з округленням; число не
  тримається → до 3 кроків назовні; ні → не пропонується).
- Рядок з `alt`, якого немає в `either_or`, → `solver_error` (інакше тихо зник би).
- min_dose поза one_of → `solver_error` (потрібен MILP; у даних немає).
- **Приклад з умови** (полуничний йогурт без молока, білок ≥ еталону 3,2, ≤ 45 грн/кг,
  reduced_sugars): нездійсненний. Конфлікт: {собівартість ≤ 45, без молока}. Послаблення:
  собівартість → 52,9 грн/кг (рецептура 52,84: соєвий напій 805,3, полуниця 100, цукор 85,8,
  ізолят сої 8,8, DVS рослинна 0,1). Інший варіант (з попередженням): з молоком — 36,03 грн/кг.
  Без «без молока» здійсненний: білок і reduced_sugars — щільні, стевія 0,04 г.
- Спостереження для даних (не B2b): у соєвій основі дешевша `bulk_starter_milk` (молочна закваска)
  — технологічно сумнівно, але алергени ловить «без молока»; базові шаблони без вимог дають
  мінімалістичні рецептури (печиво без яєць) — жорстких мінімумів ролей мало.

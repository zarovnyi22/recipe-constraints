# B5 — замір dev, одне покращення, фінальний test (модель: Opus; живий LLM ≈ 40)

1. `make eval-live SPLIT=dev`; звіт; де втрати (розбір / розгортання / дані / розв'язувач).
2. ОДНЕ покращення лише за dev (промпт → підняти PROMPT_VERSION; дані; правило); до/після в
   NOTES. Критерій: метрика «відповідність» лишається 100 %, інші не падають.
3. ОДИН раз `make eval-live SPLIT=test`, потім `make proof` (test). Нічого не налаштовуємо.
Коміти: `feat(b5): <що>` і `docs(b5): final test evaluation and proof`.
⏸ Покажи людині фінальні числа і 3 найцікавіші відповіді з proof.md (у т.ч. одну «неможливо»).
